# Printable enclosures

No CAD or printable manufacturing files have been created yet. Prior concept images establish visual direction only; they are not dimensioned designs.

## First physical prototype

Use a printed switch plate and hand wiring with the existing Waveshare C6. Start with eight core controls (four directions, OK, Back, Home, Play/Pause) and reserve two configurable positions for the ten-key baseline.

Kailh Choc V1 switches have been ordered; exact quantities and variants have not been confirmed from an order record. The owner has compatible MoErgo Glove80 MCC keycaps available. MBK caps were recommended as an alternative, but purchase was not separately confirmed.

Before fixing dimensions, verify the chosen switch drawing, plate retention, keycap sweep and spacing, switch-pin clearance, C6 board envelope, USB access, antenna clearance, and mounting method. Measure arriving samples. MCC and MBK caps share switch compatibility but must each be checked for enclosure clearance.

First deliverable: a simple switch plate and conventional handheld shell for fit testing. Later shells can vary width, length, palm curvature, texture, and visual style while retaining a shared mounting interface. Battery and IR modules remain provisional.

Keep editable source alongside eventual STL/3MF exports, with revision and print settings documented. No enclosure here is ready to print yet.
